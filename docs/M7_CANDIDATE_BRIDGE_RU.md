# M7: выборка кандидатов из сохранённых прогнозов

Ошибочные коммиты удалённой `main` сохранены в `rescue/misplaced-main-2026-11-08` на SHA `805c6f4`. Из них в основной двухсервисный путь перенесена только идея read-only выборки для планировщика. Отдельное приложение `discount_advisor/`, эксперименты с признаками и моделью, а также утверждения о результатах A/B-тестов не включены в M7.

Путь данных: `POST /v1/predict` получает признаки синтетического профиля и вычисляет вероятность неизменной моделью `lumen-temporal-catboost` 1.0.0. `plan_type` берётся из валидированного `features.plan`; результат сохраняется в `churn_predictions` с `prediction_id`, `prediction_source`, `predicted_at` и `as_of_at`. Analytics предоставляет `GET /v1/retention/at-risk?app_id=lumen`. Из возвращённых `subscribers` поля `user_id`, `plan_type`, `churn_probability`, `renewal_price_usd` можно подать в существующий `POST /v1/retention/plan` для локального предложения теста. Это не запись в Adapty и не измеренный эффект скидки.

`as_of` задаёт момент решения в UTC. Если параметр опущен, используется время самого позднего сохранённого прогноза в выбранном приложении/модели/версии. Прогноз допускается только если **оба** `as_of_at` и `predicted_at` не позже момента решения. Для каждого пользователя берётся самый поздний допустимый срез; если продление уже наступило или признаки старше `max_age_days` (по умолчанию 7), более старый прогноз не подставляется. Строки без `plan_type` учитываются в `counts.missing_plan_type` и не попадают в готовых кандидатов. Список сортируется по `churn_probability * renewal_price_usd` как порядок рассмотрения, без обещания экономии.

Пример проверки после `docker compose up --build -d`:

```bash
curl 'http://127.0.0.1:8002/v1/retention/at-risk?app_id=lumen&max_age_days=30'
M7_QA_INTEGRATION=1 .venv/bin/python -m pytest -q tests/test_m7_candidate_bridge.py
```

Данные M6 остаются синтетическими. Для рабочего применения нужны проверенные профиль подписки и цена следующего продления, признаки с временем доступности, идентификатор назначения варианта, факт показа и исход продления из авторизованных источников Adapty. Здесь такие источники не подключены. Панели Grafana остаются прежними: новый endpoint предназначен для выбора кандидатов, а не нового графика. Детальный сценарий демонстрации и перечень панелей находятся в [M6_WALKTHROUGH_RU.md](M6_WALKTHROUGH_RU.md).
