# M5-GR-001 handoff

Added `grafana/dashboards/churn-predictions.json`, a separately provisioned
Churn Predictions dashboard over the existing `grafana_ro` PostgreSQL
datasource. Panels show external prediction data status, hourly volume,
probability distribution, model version/horizon coverage and age, plus a
separate deterministic mock panel. External panels filter
`prediction_source = 'external'`; the mock panel filters `mock`. SQL exposes
no user or prediction IDs. The dashboard uses UTC and displays zero external
rows as an explicit no-data status.

Validation:

- `python -m json.tool` and `git diff --check` passed.
- Static inspection verified six unique panel IDs, the read-only datasource,
  UTC time filters, source separation and no user identifiers in SQL.
- Grafana 12 provisioned dashboard UID `churn-predictions` with six panels;
  the PostgreSQL datasource health endpoint returned `OK`.
- All six SQL queries ran against local PostgreSQL with two external boundary
  probabilities (0 and 1) and one mock row inside a rolled-back transaction.
  Distribution buckets and the external count were checked. No fixture rows
  remain.

The first Compose `up` attempt hit host port 8002 already in use. A separate
Grafana run container and PostgreSQL service in this worktree were used for
provisioning/SQL validation without disturbing the existing host stack.
No external churn model is delivered yet, so these checks use fixture rows;
they do not establish model calibration or live A/B behavior.
