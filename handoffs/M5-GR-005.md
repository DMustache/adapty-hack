# M5-GR-005 handoff

Four provisioned dashboards read `offline_users`, `offline_transactions` and `offline_imports` through the existing `grafana_ro` PostgreSQL datasource. All use UTC install-cohort filters for platform, country, acquisition channel, onboarding goal, flow and recorded test name. Panels show segment sizes and descriptive source facts only. The existing `smart-retention` UID now denotes offline campaign context; old mock scenario panels were removed. Model quality, causal A/B effects and SHAP remain explicit unavailable states.
