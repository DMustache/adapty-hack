## Boundary audit

- `ModelAdapter` requires `load`, `get_input_schema`, and `predict`, plus model ID, version, and source. `main.py` registers trusted adapters in process and calls `load` at startup; there is no upload or pickle deserialization route.
- `/v1/predict` validates features against the selected adapter's JSON Schema, rejects non-finite or out-of-range probability outputs before analytics persistence, and records the selected model version and `mock` or `external` source. The frozen request and result schemas remain at version `1.0`.
- A real adapter must be reviewed and registered explicitly. The current mock schema accepts any feature object; it is not a specification for a learned model.
