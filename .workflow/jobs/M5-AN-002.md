# M5-AN-002: Export cutoff-safe churn learning records

Provide a versioned, access-controlled export/API for the external ML owner. Include only eligible, consented pseudonymous records with decision-time features, model version, assignment/exposure metadata and observed next-renewal outcome after its horizon closes. Exclude post-decision features, unobserved labels and duplicate events; report counts of excluded/incomplete records. This feed updates churn risk only and must not be described as an uplift dataset. Acceptance: sample lineage can be reproduced from immutable source rows, and a test with a future feature or missing outcome is excluded with a reason.
