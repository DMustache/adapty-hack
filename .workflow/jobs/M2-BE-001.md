# M2-BE-001: Discount break-even + experiment planner

## Scope
Review and harden the existing `services/inference/app/economics.py` planner against the M2 contract. Compute the algebraic threshold `q_min=p/(1-d)`, where `p=1-churn_probability`; report `feasible_in_principle=false` when it exceeds 1. Allocate randomized control and discount arms deterministically from the request seed, with cents-safe maximum face-value exposure. Keep every candidate assigned exactly once; use `no_offer` when a discount is infeasible or cannot fit the remaining budget. Weekly/monthly only. No uplift model.

## Frozen contracts
Refer only to the applicable `contracts/schemas/*.schema.json`. Contact Lead for incompatible assumptions; do not modify shared contracts directly.

## Acceptance
Thresholds are correct for 10/20/30% discounts and boundary probabilities. An infeasible discount is flagged and not allocated; it is not treated as an invalid request. No user is duplicated or omitted, and allocated exposure never exceeds the budget after cent rounding. The same seed and request yield the same assignments. The response keeps `plan_source=scenario_experiment`, `modeled_discount_uplift=false`, and the disclaimer; it makes no savings or optimization claim. Preserve existing public contracts and endpoint shape.

## Tests and handoff
Run targeted unit/contract tests. Change only owned source required to meet acceptance; if the current implementation already satisfies a case, document the evidence rather than rewriting it. Commit within worktree. Send Lead commit SHA and create `handoffs/M2-BE-001.md` with modified files, tests and blockers. Lead merges to develop and runs the full gate.
