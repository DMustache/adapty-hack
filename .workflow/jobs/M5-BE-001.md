# M5-BE-001: Serve the external baseline and pin versions

Connect the existing trusted `ModelAdapter` boundary to the delivered baseline endpoint/artifact. Configure an explicit active model version, verify schema/checksum at startup, reject invalid probability output, and persist model ID/version/source with each prediction. Support candidate evaluation without automatic active-version replacement and document a rollback to the last approved version. No arbitrary deserialization or model training. Acceptance: real and mock fixtures are separately labeled; startup fails clearly on incompatible baseline; selected version stays stable across requests and can be rolled back without changing API semantics.
