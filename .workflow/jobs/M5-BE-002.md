# M5-BE-002: Execute approved A/B assignments

Implement the documented Adapty A/B integration for a reviewed risk cohort derived from versioned churn predictions. Validate pseudonymous-to-Adapty identity mapping; synchronize the frozen cohort as a typed custom profile attribute using the documented server API and `ADAPTY_SECRET` server-side; verify the segment, placement, published control/treatment flows and real offer pricing. Generate an idempotent **draft** A/B test and persist Adapty test/variation IDs. Adapty owns random arm assignment; never simultaneously serve the planner's per-user arm. Record actual assignment and exposure events with prediction/model lineage. Require explicit operator review before live activation, and do not let the gate activate a placement. Preserve the planner's budget math as a proposal only until a live enforcement mechanism exists. Block dispatch until Lead freezes the integration and event contracts. Acceptance: sandbox dry run and draft are traceable; missing mapping/content, a competing live test, and profile synchronization failure yield auditable `not_ready` or error states rather than a fabricated exposure.
