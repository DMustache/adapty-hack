# M5-BE-002: Execute approved A/B assignments

Implement a documented integration boundary that maps reviewed proposal arms to the authorized A/B system and records the resulting assignment and actual exposure events. Require explicit operator approval for live activation; retries must not reassign a customer or create duplicate exposures. Preserve control and no-offer distinctions and the existing maximum face-value budget checks. Do not infer treatment uplift or claim saved revenue. Block dispatch until Lead records the integration API, credentials/authorization path and versioned event contract. Acceptance: a sandbox A/B run yields traceable assignment/exposure IDs and an auditable failure path; the CSV proposal alone is never treated as delivered treatment.
