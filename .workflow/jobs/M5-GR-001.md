# M5-GR-001: Churn prediction output dashboard

The original task commit was integrated into `develop` before M4 and then reverted to isolate the M4 promotion. Its branch is already an ancestor of `develop`, so `integrate-job.sh` cannot apply it again. M5-GR-004 owns restoration on a new task branch.

Provision the read-only Churn Predictions dashboard described in
`docs/CHURN_PREDICTION_IO.md` using the existing `churn_predictions` table.
Show external prediction counts, churn-probability distribution, model version,
horizon and prediction age. Put mock values in a clearly separate panel. Use
UTC, no user IDs, and an explicit empty state when there are no external rows.
Do not infer calibration or treatment effect from predictions alone.

Acceptance: SQL and rendered panels agree with seeded external-prediction
fixture; read-only datasource is retained; zero-row panels remain empty, and
mock predictions cannot appear in the external-model series.
