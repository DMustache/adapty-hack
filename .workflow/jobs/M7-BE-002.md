# M7-BE-002: Generate Adapty flow A/B draft manifest

Map a `test_discount` advisor report to a reviewable manifest for a single
Adapty flow placement. Validate app/placement IDs, audience or segment,
published full-price and discount flow IDs, real store product/offer pricing,
arm weights, and the report's primary metric and guardrails. Read Adapty
state using documented CLI/API capabilities; never infer flow IDs or put
`ADAPTY_SECRET` into output or logs. If no verified discount flow exists, or
the placement has a conflicting live test, return `not_ready` with reasons.
Only create an Adapty **draft** from a fully reviewed manifest; starting or
replacing a live test requires separate placement-impact approval.

Acceptance: fixture with compatible published flows produces a correct draft
manifest and idempotent draft creation; current Lumen account without a
verified discount flow produces `not_ready` and no write.
