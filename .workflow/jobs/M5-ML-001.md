# M5-ML-001: Deliver preloaded baseline model service

`origin/model-implementation` at `253b5bd` is a cohort Discount Advisor built
from synthetic install/receipt data and assumed response scenarios. It does not
satisfy this job's per-subscriber churn probability, preloaded weights, or
model-version requirements. Its separate integration is tracked in M7.

External ML owner supplies a trusted service or artifact with preloaded baseline weights, exact runtime and checksum, versioned input/output schema, calibrated next-renewal churn probability semantics, deterministic fixture, performance budget, and provenance/evaluation report. It must expose a stable candidate version without changing the active version implicitly. Training, labels and weight updates remain outside this repository. Acceptance: Backend can verify the delivery and exercise the fixture through the adapter; mock output cannot be mistaken for learned predictions.
