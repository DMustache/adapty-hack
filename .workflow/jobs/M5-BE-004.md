# M5-BE-004: Prepare point-in-time temporal model requests

Build a versioned input builder for the 23 deployed features of `lumen-temporal-catboost` from the event sources approved in M5-LD-001. Construct one snapshot for an active paid weekly/monthly subscriber at UTC `as_of_at`, tied to the next eligible `renewal_due_at`. Read only events known by the cutoff; report missing or stale required sources explicitly instead of backfilling from future events or inventing values. Submit a stable request ID and validated features to `/v1/predict`; persist feature-source/cutoff provenance without raw customer IDs. The offline `scripts/score_temporal_snapshots.py` is a replay reference only. Acceptance: fixture requests reproduce model inputs, a future-event perturbation cannot change an earlier snapshot, and unsupported/missing-source cases do not produce a scored prediction.
