# Persist plan and expose fixed-model planning candidates

Add an additive migration without reusing `005-experiment-lineage.sql`; apply it on existing and fresh volumes. Persist optional `plan_type` immutably. Add read-only `GET /v1/retention/at-risk` per the M7 contract: require one `app_id`, default to the approved model/version, support explicit UTC `as_of`, select latest valid prediction per user at or before reference, reject predictions computed after reference, exclude due/stale records and unknown plans from planner-ready results, include prediction source and ID, return counts and capped sorted candidates. This endpoint does not create experiments or Adapty state.
