# M7-AN-001: Persist immutable advisor reports

Add a versioned migration and analytics ingestion/readback for the frozen run
and report. Store one row per `run_id`, app, audience, source SHA and dataset
digest; retain the input assumptions and candidate numbers. Equivalent retries
are duplicates, conflicting retries are HTTP 409. Use UTC, no credential or
raw user data in payloads. Grant the Grafana role SELECT only.

Acceptance: report and assumption readback is exact, original rows remain
immutable, unrelated prediction/experiment/actual-observation tables retain
their semantics, and migration works on an existing volume.
