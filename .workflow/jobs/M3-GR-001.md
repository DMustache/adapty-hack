# M3-GR-001: Prediction and experiment dashboards

## Scope
Review and improve the existing provisioned PostgreSQL datasource and Grafana dashboard. Show stored mock churn probabilities, randomized control/offer arm counts, maximum face-value discount exposure, and algebraic break-even hurdles. Use the existing `churn_predictions` and `retention_experiments` tables; no third custom API service. Dashboard provisioning must work from a clean Compose boot.

## Frozen contracts
Use the applicable `contracts/schemas/*.schema.json` and current PostgreSQL tables as read-only inputs. Ask Lead for missing fields or incompatible assumptions; do not edit analytics source, database schema, or contracts.

## Acceptance
Panels read stored rows through the read-only datasource, use UTC timestamps, and label mock risks and scenario metrics clearly. Empty data stays empty. No panel claims observed uplift, realized savings, or model validation from the synthetic fixture.

## Tests and handoff
Validate dashboard JSON and provisioning files, then verify the rendered dashboard and queries against seeded mock data after integration. Commit only owned `grafana/` files and `handoffs/M3-GR-001.md`; report commit SHA, checks, and blockers to Lead. Lead merges into `develop` and runs the M3 gate.
