# M6 — Standalone frozen churn model

**Goal:** external ML owner evaluates PoC candidates against agreed validation criteria, freezes an approved immutable version, and serves it as an independent product. This repository remains an inference/experiment client and analytics store.

**Dependencies:** M5 linked outcomes and learning feed, external validation report, product approval.

**Acceptance:** production uses an explicit frozen model version; later PoC updates cannot change its weights; rollback targets a previously approved version; lifecycle E2E tests prove version provenance and continued A/B workflow operation without claiming causal uplift.
