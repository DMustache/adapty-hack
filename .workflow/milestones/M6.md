# M6 — Hackathon demo and data handoff

**Goal:** present the already approved, unchanged `lumen-temporal-catboost` 1.0.0 artifact in a reproducible local demonstration, and document what Adapty data would be needed for a real deployment. M6 is not a production launch.

**Review guide:** `docs/M6_WALKTHROUGH_RU.md` details each stage, expected evidence, current gaps and questions for review.

**Inputs:** the fixed artifact and checksum verified in M5, the synthetic Lumen CSV snapshot, deterministic mock/simulated experiment events, and the user's permission to use this model for the hackathon. Do not train, tune, recalibrate, or replace the artifact.

**Work:** rehearse one end-to-end run showing model version and source, synthetic prediction, reviewable experiment proposal, explicitly simulated assignment/exposure/outcome lineage, read-only Grafana views, and a cutoff-safe synthetic audit export. Publish a concise data-requirements map: which fields the seed CSVs contain, which required events or observation timestamps are missing, and which Adapty exports or app events would be requested for a future real deployment. Do not create real feature feeds, customer cohorts, Adapty writes, or live tests.

**Acceptance:** a fresh local Compose run and exact-SHA gate reproduce the demo; the dashboard distinguishes mock, fixed-model synthetic predictions, and simulated experiment events; presenter material makes no production-readiness, measured uplift, saved-revenue, or real-customer accuracy claim. Existing artifact-integrity checks remain in place, but production rollback and deployment validation are outside the hackathon milestone.
