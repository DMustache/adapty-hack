# M6 — Hackathon demo and data handoff

**Goal:** present the already approved, unchanged `lumen-temporal-catboost` 1.0.0 artifact in a reproducible local demonstration, and document what Adapty data would be needed for a real deployment. M6 is not a production launch.

**Review guide:** `docs/M6_WALKTHROUGH_RU.md` details each stage, expected evidence, current gaps and questions for review.

**Inputs:** the fixed artifact and checksum verified in M5, the synthetic Lumen CSV snapshot, deterministic mock/simulated experiment events, and the user's permission to use this model for the hackathon. Do not train, tune, recalibrate, or replace the artifact.

**Work:** first present the system, five Grafana dashboards, model I/O and synthetic-versus-Adapty data boundary described in `docs/M6_WALKTHROUGH_RU.md`. Then build a deterministic local script that proposes three distinct experiment scenarios from the fixed model's synthetic predictions and records explicitly simulated assignment, exposure and outcome states. Publish the data-requirements map and synthetic audit export. Do not create real feature feeds, customer cohorts, Adapty writes, or live tests.

**Acceptance:** a fresh local Compose run and exact-SHA M6 gate reproduce all three distinct simulated tests and their full, pending-outcome and missing-exposure states; the dashboard distinguishes mock, fixed-model synthetic predictions, and simulated experiment events. The presenter material makes no production-readiness, measured uplift, saved-revenue, or real-customer accuracy claim. Existing artifact-integrity checks remain in place, but production rollback and deployment validation are outside the hackathon milestone.
