# M5 — PoC model lifecycle and learning feed

**Goal:** serve a preloaded external baseline model, run approved live A/B assignments, record exposure and renewal outcomes with prediction/model lineage, and export cutoff-safe learning records to the external ML owner. Churn-risk weights may be updated only by that external service during the PoC; no treatment-uplift model is claimed.

**Dependencies:** M4 handoff, externally delivered baseline, Lead-frozen versioned interfaces, documented A/B integration and operator authorization. Do not dispatch blocked workers before these are met.

**Acceptance:** real predictions are versioned and distinguishable from mock; the read-only Grafana dashboard displays model outputs and lineage without fabricated outcomes; a reviewed risk cohort can produce an Adapty draft test on verified content; assignments, exposures and outcomes are joinable and idempotent; learning exports exclude post-decision features and unobserved outcomes; a candidate model version can be evaluated without silently changing the active version. No live test starts in the gate.
