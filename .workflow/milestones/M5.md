# M5 — Integrate the fixed churn model and experiment lineage

**Goal:** use the existing `lumen-temporal-catboost` 1.0.0 artifact as-is, run approved live A/B assignments, and record exposure and renewal outcomes with prediction/model lineage. This project does not train, tune, recalibrate, extend or replace the model. No treatment-uplift model is claimed.

**Dependencies:** M4 handoff, externally delivered baseline, Lead-frozen versioned interfaces, documented A/B integration and operator authorization. Do not dispatch blocked workers before these are met.

**Pre-model infrastructure wave:** M5-GR-004 restores the previously integrated and reverted M5-GR-001 dashboard; then M5-GR-003 adds descriptive prediction and scenario views. M5-QA-002 independently builds the unit/contract, PostgreSQL/Grafana and fresh Compose test triangle from `docs/PREMODEL_METRICS.md`. These tasks need no external model or live Adapty writes. Record an exact-SHA checkpoint, but do not mark M5 DONE or promote it until the full dependencies and acceptance below are met.

**Offline data wave:** M5-LD-002 freezes `docs/CURRENT_DASHBOARDS.md`; M5-AN-003 imports the local synthetic users and transactions; M5-GR-005 provisions four source-honest dashboards; M5-QA-003 checks the exact SHA. Do not integrate older prediction/mock dashboard work as evidence for this wave. This checkpoint also does not mark M5 DONE. M5-LD-003 tracks model-dependent metrics, verified Adapty exports and the blind analyst comparison after the model arrives.

**Fixed model wave:** `origin/main` commits `7475a89` and `7dc9a96` supply a substantial existing implementation and the unchanged CatBoost artifact `lumen-temporal-catboost` 1.0.0. M5-ML-001 confirms its documented target and safe-use limits before activation, without changing weights or features. M5-LD-001 freezes model I/O and event sources; M5-LD-004 integrates those exact commits into `develop` before implementation jobs begin. M5-BE-001 serves this exact artifact; M5-BE-004 prepares cutoff-safe inputs. M5-AN-005 migrates prediction storage and M5-GR-010 displays trajectories; M5-QA-004 gates their integration. The replay script is a synthetic demonstration, not a production feature feed.

**Acceptance:** predictions from the pinned artifact are distinguishable from mock; the read-only Grafana dashboard displays outputs and lineage without fabricated outcomes; a reviewed risk cohort can produce an Adapty draft test on verified content; assignments, exposures and outcomes are joinable and idempotent; audit exports exclude post-decision features and unobserved outcomes. No model update or live test starts in the gate.
